# Meshtastic 公共模型型錄：維護方式

以 v20 為原始基準。公開網站為 `docs/`，資料主檔為 `data/catalog.json`，網頁版型為 `tools/template.html`。`docs/index.html` 由建置程式產生，勿直接編輯。原始作品、圖片來源與授權需個別核對；不等同實物相容或可自由再散布。

## 更新流程

1. 在更新前保留 Git 版本。編輯 `data/catalog.json`，新增或修改 `models` 中的紀錄，使用不重複的 ID；同時更新 `public_display` 裡該 ID 的中英文資料。沿用既有相近作品欄位，不確定的內容明確標示未知，不由照片推測。
2. 記錄作者、作品原始網址、資料查核日期、硬體版本、電池、配件與限制。自己的作品同樣填入作者和作品原始網址；第三方圖片及模型授權分開記錄，未知授權不得視為允許重新散布。
3. 更新 `stats` 各項數量與日期、版本、資料基準；另檢查 `tools/template.html` 中的中英文發布說明、版本與日期，避免沿用 v20 的固定文字。新增圖片時檢查署名與 `data/IMAGE_CREDITS.json`。
4. 執行 `python tools/build.py`，然後在瀏覽器開啟 `docs/index.html`，檢查總數、搜尋、新舊作品、中英文、篩選、圖片授權及連結。更新之前先確保執行結果沒有錯誤。
5. 將資料、版型、建置程式和產生的網站一併提交，Pages 設定以 `docs` 作為部署來源（若使用 GitHub Actions 則上傳 `docs/`）。檢查公開網址的實際內容。保留 Git 歷史以便回復。

## 已知限制

現有 JSON 結構較複雜，並非單純新增一列即可。初版保留原有全部資料與互動行為；之後可再製作新增表單或匯入器，應以維持原始紀錄、來源與雙語欄位為原則。大量圖片來自外部，可能失效或禁止外連。請先確認模型授權、尺寸及硬體版本。
